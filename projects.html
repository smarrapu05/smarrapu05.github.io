Enzyme Classification Using Graphs

Jan 2026 - May 2026

This project took the TUDataset ENZYMES dataset and compared machine learning methods based on the global aggregate graph statistics (such as eigenvector centrality, radius etc) with graph-based neural networks, specifically a GCN and a GAT. I primarily worked on architecting both of the neural networks in base pytorch. I think this project was one of the most fun I've done because getting in the weeds of how I want my neural network architecture built was a first-time for me. I'd worked with pre built architectures, tuning hyperparameters and measuring performance but this was my first time creating a neural network from scratch. In addition, I think building the convolutional and attention mechanisms gave me a better understanding of how neural nets work.

Graph Based Protein Structure Analysis

Aug 2025 - Dec 2025

This project was a general application of graph based statistical methods to identify changes in the structures of proteins. My section was directly comparing the structure of myoglobin and the hemoglobin alpha chain to identify differences in function. My results showed that the specific residue that allows hemoglobin to deposit oxygen (since myoglobin can only hold oxygen) is Tyrosine-140, which is a known result in the biological world, but was confirmed using Multiple Adjacency Spectral Analysis (MASE). This was my first foray into graph-based statistical methods and the fact I worked with real protein structures and got a real verified result was cool. I could talk about this project for hours and I hope to revisit it sometime in the future. At the very least work with MASE once again when I have the time or opportunity.

Planes, Trains, and Automobiles

Aug 2025 - Dec 2025

This was my undergraduate capstone, and it focused on the effects of rail transport in the EU and how it could affect the US through extrapolation. We tackled how trains affected three things: Travel Time, Emissions, and Safety. Our results found trains to be safer and emit less, which aligned with our hypotheses goin into the project. Travel time, however, was a little more nuanced with us finding the specific corridors that rail can help with to have a rather narrow distance range. Reflecting on it now, I think this project was a bit too large of an undertaking with too many different facets and data sources for an undergraduate project. But I don't think I regret it at all, it was my first time getting completely unique results from a completely unique (and rather large) set of data. Working with real data always seemed easy before I actually had to do it. I think this was a great experience for me and if there was anything I regret it was not using ggplot2 (embarassingly, I used to think base R was fine at this point).
